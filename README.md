# Pedro Jaime — Full Stack Developer

Building on both ends of the stack: Java/Spring Boot on the backend, and
whatever frontend framework the project calls for — Angular, Vue, Svelte,
Astro, Next.js.

## Featured projects

**[Portfolio_Astro](https://github.com/Nib1sin/Portfolio_Astro)**
Personal site built with Astro 7 and a single Preact island for the header,
styled with Tailwind v4. Multi-language: ES/EN/IT/DE.
Live at [pedro-develop.netlify.app](https://pedro-develop.netlify.app/it/).

**[S3_maven_microservices](https://github.com/Nib1sin/S3_maven_microservices)**
Multi-module Maven microservices setup: Eureka service discovery, API
gateway, centralized config server, and a student service consuming them.

**[ChatPDF](https://github.com/Nib1sin/ChatPDF)**
Astro + Svelte app to upload a PDF and chat with its content — upload,
processing, and chat steps as separate Svelte components.

**[SpringBoot_Docker](https://github.com/Nib1sin/SpringBoot_Docker)**
Spring Boot service packaged with Docker: Dockerfile and docker-compose for
local and deployable runs.

**[crud_products_server](https://github.com/Nib1sin/crud_products_server)**
TypeScript backend with full CRUD for a products resource.
